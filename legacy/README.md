# Arquivo legado

Esta pasta guarda a versao antiga do GastroTech antes da migracao para PHP/MySQL.

- `html`: telas antigas em HTML estatico.
- `js`: scripts antigos que usavam dados no navegador.
- `images`: imagens antigas ou nao usadas pela versao atual.

A versao principal do sistema fica em:

- `src/pages` para as telas PHP.
- `app` para conexao, autenticacao e repositorios.
- `database/database.sql` para criar o banco no MySQL/phpMyAdmin.

Use os arquivos daqui apenas como consulta ou backup.
